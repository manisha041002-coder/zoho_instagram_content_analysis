# Zoho Instagram Content Analysis

## Project Overview
This project is a manual content analysis of Zoho’s official Instagram posts.
The goal is to understand how different content types support specific marketing objectives.

This project was created for **Digital Marketing Analyst interview preparation**.

---

## Objective
- Identify content types used by Zoho on Instagram
- Map each post to a clear marketing goal
- Understand how brand, product, and leadership content are balanced

---

## Content Analysis Table

| Post | Content Type | Marketing Goal |
|------|-------------|----------------|
| Happy Holidays | Brand Awareness | Brand Recall |
| In-house band video | Engagement / Culture | Engagement |
| Voxelgrids CEO quote | Thought Leadership | Trust |
| Zoho Billing launch | Product Promotion | Lead Generation |
| Sridhar Vembu interview | Thought Leadership | Authority |
| What’s the Buzz | Product Update | Retention |

---

## Key Insights
- Zoho uses **thought leadership** to build long-term trust
- Product launches are supported with **clear value messaging**
- Cultural posts humanize the brand and increase engagement
- Content strategy balances **brand, product, and leadership**

---

## Tools Used
- Manual content observation
- Instagram (public posts)
- Spreadsheet-style classification
